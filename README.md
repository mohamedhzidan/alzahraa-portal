## ✨ ما بداخله | What's inside

- **٣٥ شاشة عمل** عبر ٣ إدارات | **35 working screens** across 3 department groups
- **مسار اعتماد ثابت** مع فصل مهام مفروض بالكود | **Fixed approval route** with enforced segregation of duties
- **١٣ دوراً وظيفياً** بصلاحيات دقيقة | **13 job roles** with granular permissions
- **١٠ تقارير** قابلة للتصفية والتصدير | **10 filterable, exportable reports**
- **لوحة تحكم** برسوم بيانية وتنبيهات تلقائية | **Dashboard** with charts and automatic alerts
- **سجل مراجعة كامل** لكل حركة | **Full audit log** of every action
- **عربي/إنجليزي** بضغطة زر (RTL/LTR كامل) | **Arabic/English** one-click switch, full RTL/LTR
- **وضع ليلي**، **تصدير Excel**، **طباعة**، **نسخ احتياطي** | Dark mode, Excel export, print, backup/restore
- **قابل للتثبيت كتطبيق** على الموبايل (PWA) | **Installable as a phone app** (PWA)

## ⚠️ تنبيه مهم | Important notice

**الوضع الحالي تجريبي.** البيانات محفوظة في متصفح كل مستخدم على جهازه فقط، وكلمات المرور غير مشفّرة.
**لا تُدخل بيانات مالية حقيقية** قبل الانتقال لقاعدة بيانات حقيقية — راجع قسم "المرحلة الثانية" في الدليل.

**This is demo mode.** Data lives in each user's own browser and passwords are not encrypted.
**Do not enter real financial data** before moving to a real database — see "phase two" in the guide.

## 🛠 التقنيات | Built with

HTML + CSS + JavaScript خالص، بدون أي إطار عمل أو خطوة بناء. ملف واحد يحكم كل الشاشات (`schema.js`) وملف واحد يحكم التخزين (`store.js`) — مصمم ليُنقل لقاعدة بيانات حقيقية دون إعادة كتابة.

Plain HTML + CSS + JavaScript — no framework, no build step. One file defines every screen (`schema.js`) and one file owns all storage (`store.js`), designed so a real database can be swapped in without rewriting anything.
